# 개인정보 처리 원칙 (개발 단계)

> 본 문서는 개발 단계의 **데이터 취급 원칙**이다. 서비스 운영용 개인정보 처리방침은 별도 확정 필요(아래 TODO).

## 커밋 금지 대상

- 실제 계약서·등기사항증명서·건축물대장·중개대상물 확인설명서 등 개인정보 포함 원본을 Git에 커밋하지 않는다.
- 이름·주소·연락처·주민등록번호·계좌번호 등 민감정보를 커밋하지 않는다.
- **모델 가중치·체크포인트·어댑터 파일**을 커밋하지 않는다. 메타데이터만 `data/model-metadata/`에 둔다.
- 생성된 대용량 벡터 인덱스를 커밋하지 않는다.

## Git 제외 경로 (`.gitignore` 반영됨)

- `data/raw/*` — 실제 원본 전체 제외 (`data/raw/README.md`만 예외)
- `data/uploads/`, `uploads/` — 업로드 원본
- `data/processed/**/*` — 가공 산출물 (각 폴더 `README.md`만 예외)
- `data/rag/index/`, `*.faiss`, `*.index`, `*.pkl`, `chroma/`, `*.sqlite3` — 벡터 인덱스
- `*.safetensors`, `*.gguf`, `*.bin`, `*.pt`, `*.ckpt`, `adapter_model.*`, `**/checkpoints/` — 모델 가중치

## 샘플·데이터셋

- `data/sample/`, `data/datasets/`에는 **가상 또는 완전히 비식별화한 데이터만** 둔다.
- 파인튜닝 데이터셋도 비식별·합성 원칙을 따른다([`training-dataset.md`](training-dataset.md)).
- 실제 자료와 생성 데이터를 명확히 구분한다. 실제 원본에서 파생한 비식별본은 재식별 불가함을 확인한 뒤 둔다.

## 업로드 문서 저장 (구현됨)

- 업로드 원본(계약서·등기사항증명서·확인설명서·증빙)은 `UPLOAD_DIR`에 **Fernet 대칭키로 암호화해서** 저장한다. 저장 경로에 `.enc` 접미사가 붙는다. (`backend/app/core/crypto.py`)
- 키는 `DOCUMENT_ENCRYPTION_KEY`를 우선 사용하고, 없으면 로컬 MVP 한정으로 `JWT_SECRET`에서 파생한다. **운영 전환 시 별도 키 관리·회전 필요(TODO).**
- 저장소 파일명은 uuid이며 사용자 원본 파일명은 DB에만 남는다. 합성 fixture(`data/sample/**`)는 암호화 대상이 아니며 평문 그대로 읽는다.

## 외부 전송 경로별 비식별화 (경로마다 다름 — 하나로 뭉뚱그리지 않는다)

| 입력 경로 | 로컬 토큰 치환 | 비고 |
|-----------|----------------|------|
| 디지털 PDF·TXT 텍스트 추출 | **적용** | `PiiTokenizer`로 치환 후 전송, 응답에서 복원. 치환 실패 시 요청 중단 |
| 생성·재검토·RAG 요청 | **적용** | 같은 토큰 경계 사용 |
| 스캔 PDF·사진 VLM 구조화 | **미적용** | 이미지 픽셀은 로컬 OCR 없이 치환할 수 없다(OCR을 Gemini VLM에 통합한 2026-07-14 결정의 귀결). 개인정보가 보이는 상태로 전송된다 |

- 스캔 경로의 이 한계는 업로드 화면에 그대로 고지한다. 문서·기획서에서 **"전 경로 비식별화"로 표현하지 않는다.**
- 로컬 OCR을 도입하면 스캔 경로도 텍스트 경로와 같은 치환 경계로 옮길 수 있다(미정 — TODO).

## 로그·오류

- 개인정보·문서 내용을 로그·오류 메시지에 남기지 않는다(backend 규칙).
- 프롬프트·중간 산출물을 저장할 때 개인정보를 제거하거나 마스킹한다.
- 생성 provider 요청은 로컬에서 이름·주소·계좌·주민번호·전화·이메일을 결정론적 토큰으로 치환한다. 매핑은 외부 요청과 차단 로그에 포함하지 않고 출력 복원에만 사용한다.
- 디지털 PDF·TXT의 Gemini 구조화 요청도 같은 로컬 토큰화·복원 경계를 사용한다. 스캔·사진 원본 VLM 전송은 위 표대로 치환 없이 전송되며 사용자에게 고지한다.
- 현재 로컬 게이트는 추가 패키지 없는 형식형·명시 라벨 정규식 범위다. 문맥형 탐지 패키지와 운영 기준은 확정 전 설치·확대하지 않는다.
