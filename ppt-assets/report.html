해석 시 주의

  • 발표에 쓸 성능 수치는 운영 경로 그룹이다. 회귀 기준선의 100%는 정규식·BM25 폴백(offline-regex-bm25-template-v3) 값이며 서비스 성능이 아니다.
  • 전 구간 합성 test 기준이다. 실제 계약서 일반화 성능이나 법률적 정확도를 뜻하지 않는다. 문서는 생성기가 템플릿으로 찍은 10건이다.
  • 일반 RAG는 provider 경로로도 recall 1.0이다. 다만 27쿼리 중 6건은 rerank 없이 hybrid 순위로 확정됐고(로그상 rerank 18~21콜), precision은 화이트리스트 때문에 항상 1.0이다.
  • 가드레일은 별도로 검증된다. 근거 없는 생성 6건을 전부 차단했고(6/6), 금지 표현 0건, grounding 위반 0건이다.
  • RAG 코퍼스 무결성은 측정 당일 확인했다. 공식 출처 6건의 content_sha256·metadata_sha256과 런타임 청크 메타데이터가 원문 파일과 모두 일치했고 data/check_dataset.py도 통과했다. 이전에 보고된 SRC-HTA-LAW·SRC-HTA-DECREE 해시 불일치는 현재 브랜치·main 모두에서 재현되지 않는다.

  • 비용은 하한값이다. 임베딩 46콜·재순위 23콜이 usage를 반환하지 않아 $0으로 기록된다. Cohere는 Trial key라 실제 청구도 0이지만 유료 전환 시 추가된다.
